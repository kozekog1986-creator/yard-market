# YARD — многопользовательская доска объявлений

Flask + SQLite. Есть регистрация по email с подтверждением, вход, профили, создание/редактирование/удаление объявлений, поиск и фильтры, сообщения продавцам и входящие. Это локальная основа для обычной доски объявлений, а не готовый публичный продакшен-сервис. Соблюдайте применимые законы и не размещайте запрещённые товары.

## Запуск Windows
1. Установите Python 3.10+.
2. Распакуйте архив и дважды нажмите `run.bat`.
3. Откройте http://127.0.0.1:5000.

## Почта
Без SMTP приложение работает в тестовом режиме: ссылка подтверждения печатается в консоль, где запущен сервер. Для настоящей отправки задайте переменные окружения `SMTP_HOST`, `SMTP_PORT` (обычно 587), `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_FROM`. Также задайте постоянный случайный `SECRET_KEY`. Перезапустите сервер. Не используйте пароль личной почты — используйте пароль приложения/учётные данные почтового провайдера.

## Перед публикацией в интернете
Нужны HTTPS, production WSGI-сервер, постоянный SECRET_KEY, настройка почты, резервные копии БД, лимиты запросов, CSRF-защита, политика конфиденциальности, модерация и проверка безопасности. Сообщения сейчас представлены лентой входящих, без realtime-чата.
